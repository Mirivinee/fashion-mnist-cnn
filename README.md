# Fashion-MNIST Model Comparison

This project compares a baseline neural network with convolutional neural networks (CNNs) for classifying images from the Fashion-MNIST dataset.

## Project Overview

The notebook applies the original MNIST model to Fashion-MNIST as a baseline, then builds and evaluates CNN models. It also tests CNN improvements and compares their performance.

## Dataset

Fashion-MNIST contains 28×28 grayscale images in 10 clothing categories.

## Models

- **Baseline model:** The original MNIST model evaluated on Fashion-MNIST.
- **Original CNN:** A CNN trained on Fashion-MNIST.
- **Improved CNN 1:** CNN with batch normalization.
- **Improved CNN 2:** CNN with a third convolutional block.

## Notebook Contents

- Dataset exploration and visualization
- Image preprocessing and validation split
- Baseline model evaluation
- CNN training and accuracy/loss curves
- Classification report and confusion matrix
- Examples of misclassified images
- CNN improvement experiments and model comparison
- Reflection questions
